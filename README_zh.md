# k-goku

使用 GokuRakuJoudo 生成 Karabiner 配置的个人键位方案。

## Karabiner 是什么？

[Karabiner](https://pqrs.org/osx/karabiner/) 是一款强大且稳定的 macOS 键盘自定义工具。

- 你可以不受限制地重映射任何按键。
- 你可以加速按键的重复速度。Karabiner 提供了许多常用设置，只需在列表中勾选即可启用。如果列表中没有你需要的设置，你也可以自行添加。

Karabiner 拥有许多提升键盘操作效率的实用功能：

- 你可以在任何地方使用 Emacs 风格的操作。
- 你可以在任何地方使用 Vi 风格的操作，还可以通过键盘操控鼠标。

通过改造你的键盘，一切皆有可能！

## GokuRakuJoudo 是什么？

[Goku](https://github.com/yqrashawn/GokuRakuJoudo) 是一款让你轻松管理 Karabiner 配置的工具。

Karabiner Elements 使用 JSON 作为配置文件格式，这往往会导致数千行 JSON（有时甚至超过 20,000 行），使得编辑配置和迭代键位映射变得非常困难。

Goku 使用 [edn 格式](https://github.com/edn-format/edn) 来解决这个问题。

## k-goku 是什么

k-goku 是一套使用 GokuRakuJoudo 生成 Karabiner 配置的个人自定义键位规则方案。☺

### Hyper 模式

Hyper 模式充分利用了 CapsLock 键。当按住 `CapsLock` 时，Hyper 模式将被激活以触发后续动作；单独按下时则发送 `Escape` 键。

#### Hyper 模式 - 控制键

Hyper 模式可以作为 `ctrl` 键使用，主要用于终端中的常用操作：

| 按键 | 效果                              |
|------|-----------------------------------|
| `a`  | tmux 前缀键                       |
| `c`  | 发送 SIGINT 信号终止进程           |
| `z`  | 发送 SIGTSTP 信号挂起进程          |
| `d`  | 退出命令（`exit()`）               |

#### Hyper 模式 - 导航 [VI 风格]

使用 VI 风格的光标移动。

| 按键 | 效果           |
|------|----------------|
| `h`  | 向左移动       |
| `j`  | 向下移动       |
| `k`  | 向上移动       |
| `l`  | 向右移动       |
| `w`  | 向前移动一个词 |
| `b`  | 向后移动一个词 |

同时按下 `cmd ⌘` 键可以在移动光标时选中文本。

同时按下 `opt ⌥` 键则移动鼠标指针。

#### Hyper 模式 - 鼠标键

使用方向键模拟鼠标指针操作。

| 按键   | 效果                       |
|--------|----------------------------|
| `←`    | 指针向左移动               |
| `→`    | 指针向右移动               |
| `↑`    | 指针向上移动               |
| `↓`    | 指针向下移动               |
| `↵`    | 鼠标左键点击               |
| `⌘ ↵`  | 鼠标右键点击（上下文菜单） |

#### Hyper 模式 - 删除

轻松删除文本。

| 按键   | 效果                           |
|--------|--------------------------------|
| `n`    | 向后删除一个词                 |
| `m`    | 向后删除一个字符               |
| `,`    | 向前删除一个字符               |
| `.`    | 向前删除一个词                 |
| `⌘ n`  | 从光标删除到行首               |
| `⌘ m`  | 从光标删除到行首               |
| `⌘ ,`  | 从光标删除到行尾               |
| `⌘ .`  | 从光标删除到行尾               |

#### Hyper 模式 - 其他

Hyper 模式下的其他杂项功能。

| 按键     | 效果                    |
|----------|-------------------------|
| `esc ⎋`  | 发送真正的 `CapsLock` 键 |
| `~`      | 系统内置截图             |

### SimLayer 模式

SimLayer（同时按层）是指当你按下一个键的同时（几乎同时）按下另一个键来触发不同效果的功能。

#### 逗号模式 [,] 作为触发键

按下 `,` 触发逗号模式：

| 按键 | 输出 | 说明       |
|------|------|------------|
| `a`  | `[`  | 左方括号   |
| `s`  | `]`  | 右方括号   |
| `d`  | `&`  | 与号       |
| `f`  | `*`  | 星号       |
| `q`  | `_`  | 下划线     |
| `w`  | `+`  | 加号       |
| `e`  | `%`  | 百分号     |
| `r`  | `^`  | 插入符     |

#### 句号模式 [.] 作为触发键

按下 `.` 触发句号模式：

| 按键 | 输出 | 说明       |
|------|------|------------|
| `a`  | `~/` | 主目录     |
| `s`  | `.*` | 所有类型   |
| `d`  | `(`  | 左圆括号   |
| `f`  | `)`  | 右圆括号   |
| `q`  | `-`  | 连字符/减号 |
| `w`  | `=`  | 等号       |
| `e`  | `{`  | 左花括号   |
| `r`  | `}`  | 右花括号   |

#### 启动器模式 [/] 作为触发键

按下 `/` 触发启动器模式。该模式支持 **toggle 切换**：按一次激活/聚焦应用，当应用已在前台时再按一次则隐藏该应用。

| 按键 | 应用     | 说明       |
|------|----------|------------|
| `t`  | Telegram | 即时通讯   |
| `q`  | QSpace   | 文件管理   |
| `c`  | Cursor   | 代码编辑器 |
| `w`  | WeChat   | 微信       |
| `i`  | iTerm2   | 终端       |
| `d`  | Dia      | 网页浏览   |
| `s`  | Spark    | 邮件客户端 |
| `f`  | Feishu   | 飞书       |
| `h`  | -        | 隐藏当前应用（Cmd+H） |

### 其他

- 单独按下右 Shift 键切换输入法
- 单独按下右 Command 键触发 Command-Tab 在最近两个应用间切换
- 右 Option 键改为四修饰键组合 `⇧⌃⌥⌘`，单独按下时发送 `F17`
- 按两次 Command-Q 退出应用

## 安装

1. 安装 [Karabiner-Elements](https://pqrs.org/osx/karabiner/)
2. 在 Karabiner-Elements 中创建名为「Default」的配置方案（这会在 ~/.config/karabiner/ 目录下生成 karabiner.json 文件供 Goku 使用）
3. 安装 [Goku](https://github.com/yqrashawn/GokuRakuJoudo)

```
brew install yqrashawn/goku/goku
```

4. 安装 k-goku

```
curl https://raw.githubusercontent.com/kchen0x/k-goku/master/karabiner.edn > ~/.config/karabiner.edn

goku
```
